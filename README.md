# ☀️ Laboratorio Solar Interactivo

Aplicación web educativa desarrollada en **HTML, CSS y JavaScript** para explicar de forma interactiva el funcionamiento de un **sistema fotovoltaico**.

El simulador fue diseñado para utilizarse en **casas abiertas universitarias**, permitiendo que estudiantes de preparatoria experimenten cómo se genera y utiliza la energía solar.

---

# 🎓 Programa académico

**TSU en Turbo Solar**
**Ingeniería en Energía y Desarrollo Sustentable**

---

# 🎯 Objetivo del simulador

Permitir que los estudiantes comprendan de manera visual:

* Cómo funciona un **sistema fotovoltaico**
* Cómo afecta la **irradiancia solar**
* Cuántos **paneles solares** necesita una casa
* Cómo fluye la energía dentro del sistema
* Cómo se **almacena la energía en baterías**

---

# 🧩 Módulos del laboratorio interactivo

## 1️⃣ Componentes del sistema

Muestra los elementos principales de un sistema fotovoltaico:

* ☀️ Sol
* 🔋 Panel solar
* ⚡ Regulador de carga
* 🔌 Inversor
* 🔋 Batería
* 🏠 Casa (consumo)

Cada componente puede seleccionarse para mostrar su función.

---

## 2️⃣ Simulación del día

Simula el ciclo solar:

* 🌅 Mañana
* ☀️ Mediodía
* 🌇 Tarde
* 🌙 Noche

La irradiancia cambia automáticamente y se actualiza la producción del panel.

---

## 3️⃣ Simulación solar

Permite modificar la **irradiancia solar** con un control deslizante.

### Modelo energético utilizado

[
P = Irradiancia \times 0.45
]

Donde:

* **1000 W/m² → 450 W por panel**
* **500 W/m² → 225 W por panel**

---

## 4️⃣ Construye tu sistema

El usuario puede agregar paneles solares para diseñar su sistema.

Cada panel tiene una potencia de:

```
450 W
```

La potencia total instalada se calcula automáticamente.

---

## 5️⃣ Diseña tu sistema solar

El objetivo es alimentar una casa con un consumo aproximado de:

```
2700 W
```

Por lo tanto, el estudiante debe instalar aproximadamente:

```
6 paneles solares
```

---

## 6️⃣ Flujo de energía

Simulación visual del flujo energético:

```
Sol → Panel → Regulador → Batería → Inversor → Casa
```

Incluye:

* Animación del flujo eléctrico
* Carga progresiva de la batería
* Consumo energético de la casa

---

## 7️⃣ Quiz solar

Actividad rápida para reforzar conceptos.

Ejemplo:

**¿Qué convierte la luz solar en electricidad?**

✔ Panel solar
